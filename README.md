## ✨ Возможности

- **35 заданий × 4 варианта (A–D)** — устная + письменная части
- **Устная часть (1–5)** — отдельный блок с:
  - критериями оценивания ФИПИ
  - самооценкой по каждому заданию (0…max)
  - полем для заметок
  - эталонами ответов
  - отдельным **таймером 15 минут**
- **Письменная часть (6–35)** — 4 модуля с фильтром:
  - 👂 Аудирование (6–11)
  - 📖 Чтение (12–17)
  - ✍️ Письмо (18–19) — развёрнутые ответы
  - 📚 Грамматика и лексика (20–35)
- **3 режима:** 🎓 Тренировка / 📝 Экзамен / 🔁 Ошибки
- **Таймер 90 минут** на письменную часть с предупреждениями
- **RU / EN** — интерфейс и формулировки заданий
- **Тёмная / светлая тема**
- **Экспорт результатов** в `.txt` (включая устную часть), печать
- **Один файл `index.html`** — офлайн, без сервера, CDN и зависимостей
